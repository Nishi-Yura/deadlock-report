パッチまとめ ・ 2026.11.26 ・ Minor Update

11/26 アップデート（感謝祭）

公式の扱いは「マイナーアップデート」ですが、ソウル経済、ダメージ計算のルール、Haunts と Midboss、30体以上のヒーローに変更が入った大きめのパッチです。

配信2026.11.26
前回の大型City Never Sleeps
変更ヒーロー33 体

まずはここだけ

  1. 1序盤が柔らかく、後半が痛く。基礎HP −8%（その分ブーンでのHP成長へ再配分）、ブーン毎の銃ダメージ成長 +5%（Haze, Holliday, Venator, Vindicta, Warden, Wraith は対象外）。
  2. 2逆転ボーナスが弱く。カムバックソウル約 −5%。Unstable Rift の劣勢ボーナスはネットワース差20%で最大（以前は15%）。
  3. 3ファーストキル報酬アップ。各プレイヤーの初キル 125 → 175 ソウル。
  4. 4ダメージ増減の計算を統一。Rebuttal や Curse などの与ダメ増減が全種類のダメージに乗るように。重ね掛けは逓減。
  5. 5Wraith に大きな弱体。移動速度・HP回復・スプリント・カード生成速度がまとめて低下。
  6. 6練習モードに Bot Drills。Bebop のフック避け、Graves のパリィ読みなど16種類の対面練習。

全体の変更

ソウル経済・逆転要素

  • カムバックソウルを全ソース約 −5%。
  • 自チーム平均より稼いでいる人のカムバックソウルは、一部がチームの貧しい2人へ回る。平均ちょうどで0%、平均+20%で最大80%（以前は「敵平均より上なら一律70%」）。
  • Unstable Rift の劣勢ボーナス（耐性・占領速度・トルーパー数）は差20%で最大。小さい差ではボーナスが減る。
  • トルーパーの対ヒーローダメージ +10%。ソウルオーブが落ちる範囲 45m → 42m、地面のオーブ取得範囲 −7%。
  • 木箱のソウル：通常 23+1.8/分 → 18+2.0/分、大 46+3.6/分 → 36+4.0/分（序盤は減り、後半は増える）。
  • 浮遊回復スナックの復活 180秒 → 120秒、取得範囲 3m → 3.5m。

Haunts・Midboss・Rejuvenator

  • Haunts：報酬 −5%、スキルダメージ +30%、弾耐性 +5%、スピリット耐性 +10%。劣勢時の Haunted Souls 確保速度は最大 +50% → +75%。
  • Sinner's Sacrifice の1撃ダメージ 80 → 80 + 最大HPの1%。
  • Midboss：HP 15600+234/分 → 12500+250/分、与ダメ +30%、全体咆哮の閾値 25% → 30%、連射速度低下効果は半減。
  • Rejuv クリスタル取得時に、ウルト以外のデバフを解除（回復の前）。クリスタルを殴った報酬はチーム全員で均等割り。

Permanent Buffs（永続バフ）

  • 弾耐性・スピリット耐性 0.5/0.75/1% → 0.5/1/1.5%、スキル射程 0.25/0.5/0.75% → 0.5/0.75/1%、移動速度3段目 0.3m → 0.4m。
  • スキル射程バフの2・3段目が範囲に効いていなかった不具合を修正。

戦闘・移動のルール

  • 空中ジャンプに失敗すると、次の地上ジャンプの空気抵抗が連続回数に応じて増える（バニーホップのマクロ対策）。
  • ヘビー近接：途中で行動不能・打ち上げを受けると即座にパンチが確定。
  • 与ダメ増加・減少（Rebuttal, Inhibitor, Cheat Death, Curse, Haunting Shot など）が、固定武器ダメージ・アイテムの固定ダメージ・近接スキルの基礎値・武器ダメ依存スキルにも乗るように。
  • 与ダメ増加同士・減少同士の重ね掛けは全ダメージ種で逓減。Silencer などの「スピリット与ダメ低下」同士も逓減。召喚物は持ち主の現在の増減値を使う。
  • 壁際のテレポート失敗、ノックバックの挙動、Steam Vent 内の索敵など、多数の不具合を修正。

UI・表示

  • スタミナ横に残り空中ジャンプ/ダッシュ数を表示（使い切ると赤）。Alt でジップラインブーストのCDを表示。
  • 上部バーに Rejuvenator の残り時間、クリスタルに番号。Unstable Rift の劣勢ボーナスも HUD に表示。
  • 武器ステータスに散弾数、Shiv / Yamato / Viscous の副射撃、Deadman Danny のチャージ射撃を表示。
  • 試合後グラフに「与えたCC」「受けたCC」「軽減したダメージ」を追加。ヒーロー変更時にビルドを即ロード。

サンドボックス ・ Street Brawl

Bot Drills（Testing Tools → Bots++）

目の前に敵ボットを出して、特定の動きへの対処を練習できる機能。収録は16種類：Abrams の突進、Baba ×2、Bebop のフック避け、Billy の連携、Deadman Danny の急降下、Graves のパリィ読み、Grey Talon の空爆、Holliday の樽、Lash の叩きつけ、McGinnis の壁＋弾幕、Paradox の入れ替え、Silver の狼形態、Vindicta の飛行、Viscous ×2。

Street Brawl

  • 最終ラウンドのブーン上限 34 → 35。Cloak of Opportunity が Fear も防ぐように。
  • ヒーローごとのおすすめアイテムが、現在の人気アイテムから自動で更新されるように（11/24 から反映済み）。
